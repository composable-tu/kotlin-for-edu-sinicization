# 为什么要教 Kotlin？

::: info
本文翻译自：https://kotlinlang.org/education/why-teach-kotlin/
:::

## 学术界广泛认可

据我们所知，已有超过 300 所大学在各类课程中教授 Kotlin，包括面向对象编程、函数式编程、软件开发、编程入门、移动应用开发、并发编程、科学计算编程等（来源：内部《Kotlin 教学研究》报告，2023 年 6 月）。

::: info
在《泰晤士高等教育》2023 年世界大学排名前 100 的大学中，有 32 所将 Kotlin 纳入了课程体系。[大学列表](https://kotlinlang.org/education/courses/)
:::

> 我教授使用 Kotlin 进行软件工程的课程。我们还开设了一门独立的 Android 开发课程。因此，我可以使用一种学生在其他课程中也能用到的语言进行教学。
>
> —— 尤金尼·图门采夫（Eugeniy Tyumentcev），鄂木斯克国立大学

> 在许多从 Java 过渡到 Kotlin 的课程中，我们正在考虑采用“Kotlin 优先”的教学方法。
>
> —— 伊蒙·德·利斯特（Eamonn De Leastar），沃特福德理工学院

## 行业主流语言

Kotlin 已被 Google、亚马逊、Twitter、Reddit、Netflix、Uber、Slack 等顶尖企业广泛采用，这仅是其中一部分。

传授专业的软件工程实践有助于提升学生的就业前景。鉴于 Kotlin 是一项极具市场价值的技能，学生们往往对学习它更加热情。

每两名开发者中就有一人计划学习一门新语言。Kotlin 是开发者最想学习的三大语言之一。[《2022 年开发者生态系统现状报告》](https://www.jetbrains.com/lp/devecosystem-2022/)

2020 年，Kotlin 成为 JVM 平台上第二受欢迎的编程语言。[《Snyk.io 2020 年 JVM 生态系统报告》](https://snyk.io/blog/kotlin-overtakes-scala-and-clojure-to-become-the-2nd-most-popular-language-on-the-jvm/)

::: info
Kotlin 一直稳居最热门软件工程技能之列。[Hired《2023 年软件工程师现状报告》](https://hired.com/state-of-software-engineers/2023/)
:::

> 学生们很高兴有机会用他们可能听说过的编程语言进行编程。
>
> —— 瑞安·斯坦西弗（Ryan Stansifer），佛罗里达理工学院

> 学生们非常开心。他们能够快速开发出有用的软件。
>
> —— 卡罗伊·马查利克（Károly Machalik），潘诺尼亚大学

## 多平台

Kotlin 是教授 Android 开发的首选语言。它也被广泛应用于多平台开发、Web 开发、服务器端编程、数据科学以及其他计算机科学领域的教学。

::: info
JetBrains 推出的 Kotlin Multiplatform Mobile 和 Compose Multiplatform 框架可帮助开发者在 Android 和 iOS 应用之间复用代码。这些框架现已提供对 Kotlin 编译为 WebAssembly 的实验性支持。[Google for Developers 博客，2023 年](https://developers.googleblog.com/2023/05/bringing-kotlin-to-web.html)
:::

> 冗余代码的减少有助于我们快速识别学生在哪些基础的 Android 概念上存在不足。由于基本语法或语言问题导致故障的概率降低了，学生因此能够将精力集中在更根本的软件设计问题上。
>
> —— 雅各布·马斯（Jakob Mass），塔尔图大学

## 互操作性

与 JVM 生态系统的无缝互操作性意味着 Kotlin 可以利用众多现有的库。Kotlin 插件内置了一个 Java 到 Kotlin 转换器（J2K），可自动将 Java 文件转换为 Kotlin。

::: info
Kotlin 还可以编译为独立的原生二进制文件，支持所有主流操作系统。[Java 到 Kotlin 转换器](https://kotlinlang.org/docs/mixing-java-kotlin-intellij.html#convert-java-files-to-kotlin)、[Kotlin/JVM](https://kotlinlang.org/docs/jvm-get-started.html)、[Kotlin/Native](https://kotlinlang.org/docs/native-get-started.html)
:::

> Kotlin 不仅开发速度更快，代码逻辑也更易理解；近 100% 的向后兼容性使得将 Java 代码转换为 Kotlin 变得轻而易举，同时还能充分利用 Java 中的所有可用库；学生们似乎也能很快掌握它。
>
> —— 保罗·佩雷拉（Paulo Pereira），里斯本高等工程学院

> 在即将开设的《编程入门》课程中，我们选择了 Kotlin，因为我们需要一种面向 JVM 且能与其生态系统无缝互操作的语言：这对我们的市场而言至关重要。
>
> —— 大卫·沃恩（David Vaughn），密苏里大学圣路易斯分校

## 支持多种编程范式

Kotlin 以优雅的方式融合了所有主要的编程范式，使得在同一种语言中即可使用函数式、命令式、面向对象或过程式编程。得益于 Kotlin 对协程的支持，并发和并行概念得以自然呈现。

::: info
Kotlin 支持函数式、命令式、面向对象和过程式编程。
:::

> 您可以向初学者教授过程式编程，而无需解释类。因此，您的课程内容将更加连贯。
>
> —— 阿列克谢·米茨尤克（Alexey Mitsyuk），俄罗斯高等经济大学

> Kotlin 不仅对面向对象编程提供了强力支持，同时也支持函数式编程。
>
> —— 费尔南多·马格诺·昆塔奥·佩雷拉（Fernando Magno Quintão Pereira），米纳斯吉拉斯联邦大学

> 事实上，我的 Kotlin 学生比 Java 学生更深入地理解面向对象的概念。
>
> —— 桑·斯库拉塔纳库尔柴（San Skulrattanakulchai），古斯塔夫·阿道夫学院

## 现代、简洁且安全

Kotlin 让学生能够专注于表达自己的想法，因为他们无需编写过多的冗余代码。代码量减少也意味着需要测试和调试的代码更少。这种语言设计使 Kotlin 成为一种高生产力的语言，同时也简化了作业批改和理解学生代码的过程。

Kotlin 通过静态类型检查和自动内存管理，有助于编写正确的程序。它杜绝了空指针解引用，且不存在显式指针或无法检测到的未初始化变量。

::: info
类型安全、空值安全以及富有表现力的语法，是教育工作者最青睐的 Kotlin 特性。（来源：一项关于 Kotlin 教学的内部研究）
:::

> Kotlin 的简洁性是我最喜欢的特性。我曾将自己的一些 Java 编程课程作业移植到 Kotlin 上，发现代码通常能缩减到原大小的 50%。作为一名教师，在向学生演示操作时，能够用更少的代码也能让我受益匪浅。
>
> —— 尼克·埃福德（Nick Efford），利兹大学

> 语法简洁。用更少的代码实现更多功能。同时，Kotlin 还具备协程等高级特性。
>
> —— 扎伊德·阿尔塔哈特（Zaid Altahat），西北大学、威斯康星大学帕克赛德分校

> Kotlin 的优势之一在于强类型与空安全性的完美结合。
>
> —— 马克·扎斯拉夫斯基（Mark Zaslavskiy），圣彼得堡圣光机大学

> 运行时错误更少是 Kotlin 的优势。空安全是我最喜欢的 Kotlin 特性。
>
> —— 杰弗里·帕翁（Jeffrey Paone），科罗拉多矿业学院

## 开发工具

许多顶尖的专业开发工具都已与该语言深度集成。IntelliJ IDEA Ultimate 将 Kotlin 作为一等公民支持，且对教育工作者和学生免费开放。它提供了强大的生产力功能，例如智能代码补全、代码检查、可视化调试器等。

此外，还有专为教育设计的 JetBrains Academy 插件，可协助学习与教授 Kotlin 编程。教育工作者既可使用现有的互动课程，也可创建自定义课程，其中包含动手实践作业和编码练习任务。集成测试功能将自动检查作业并提供反馈。

Kotlin 提供了丰富的教学资源、学习资源及社区资源。

> 快试试吧！您一定会爱上它的。语言设计成熟，IDE 支持非常出色，文档也非常棒。
>
> —— 马里乌什·诺沃斯塔夫斯基（Mariusz Nowostawski），挪威科技大学

> JetBrains 为 Kotlin 配备了目前最优秀的工具集，从而简化了开发过程。
>
> —— 亚历山大·诺齐克（Alexander Nozik），莫斯科物理技术学院
